# Live test plan — post-v0.8.0 and Phase 4 options (2026-09-30)

Everything left on the beta-feedback plan needs the game running. Each test
below says what to set up, what to do, what the client log should say, and
what to report back if it doesn't. Run with a client built from main
(64cfbf1 or later) so the Phase 4 options and the gil-floor revert are in.

Setup common to all: a generated seed with `vehicle_unlocks: true`,
`enemy_power: 50`, `ap_multiplier: 2`, `triple_triad_rules: no_random`,
`triple_triad_rule_checks: true`, `story_keys: story`. A Disc 1 save on the
world map near Balamb (the slot1_save02 wm save from Session 7 works).

## A. AP Multiplier (new, unverified live)
1. Junction one GF to Squall, note its current ability's AP in the GF menu.
2. Win one random battle. Read the AP awarded on the results screen.
3. Back on the world map, within a second the log should say
   `AP x2: +N bonus AP` where N equals the award. Open the GF menu: the
   counter should have risen by twice the award.
4. Also: let a counter fill from the bonus (get within one award of the
   cost). Confirm the ability completes at the NEXT battle's award.
Report: whether N matched, and whether the menu value agrees.

## B. Enemy Power (new, unverified live)
1. Start a battle. The log should say once:
   `Enemy Power: enemies fight at 50% (HP, Str, Vit, Mag, Spr)`.
2. Scan an enemy (or compare damage): its HP should be half its usual, and
   hits should land for roughly half.
3. Fight one boss (Fire Cavern Ifrit is fine) to see it also applies.
4. Watch for anything odd: an enemy that visibly re-scales mid-fight (its
   HP bar halving again) would mean the max-HP change detection is wrong.
Report: Scan HP vs the wiki value; anything odd.

## C. Triple Triad rules (new)
1. Play one card game in Balamb (Random is not native there — fine) and
   one in Dollet if reachable. The Dollet game must not offer Random.
2. `/ff8verify` prints `tt_rules=`; every byte must have bit 3 clear.
Report: the tt_rules hex.

## D. Magical Lamp with Diablos already owned (the open question)
1. On a save where GF Diablos is owned (any source) and the "Magical
   Lamp: Diablos" check is still missing, hold a real Magical Lamp.
2. Open the item menu on the world map and try to use the Lamp.
Report ONE of: (a) it is greyed out / unusable, (b) it is usable but nothing
happens, (c) the Diablos fight starts. The fix differs per answer: (a) or
(b) means the client should hide GF Diablos while a Lamp is held and the
check is missing; (c) means the original report was something else.

## E. Fisherman's Horizon on Disc 1 with the Ragnarok
The entrance script gates FH at moment 636 (foot/car) or 3900 (Ragnarok),
so a Disc 1 entry should be impossible unless a faked 3167 was live.
1. On Disc 1 with the ship, fly to FH and press the land button over the
   town. Then walk onto it on foot.
2. Immediately run `/ff8moment`: it must say the true moment, not 3167.
Report: did you get in, and what /ff8moment said. If you got in, also run
`python tools/poc_story_keys.py entries` (AP client closed) and paste
entries 18-20.

## F. Lunatic Pandora with the early Ragnarok
After the ship spawns from a battle on Disc 1, fly to the Esthar continent.
Report: is Lunatic Pandora visible / solid? (Only cosmetic unless it blocks
something — then it goes on the list.)

## G. Regression spot-checks from v0.8.0
- Receive a spell you have never drawn (ask a co-op partner or use a filler
  item), then fight one battle. No `First Draw:` check must fire; the log
  may say nothing. Then draw it for real from a draw point: the check fires
  and the log says `<spell>: drawn for real -> First Draw can count`.
- Kill the client mid-battle (Task Manager) with vehicle_unlocks on, save
  from the menu after the battle, restart the client: it must log
  `Repaired the story moment: 3167 -> <true>` on the first tick.
- Play a Triple Triad game: no `Battle won:` line in the log.

## H. Gil Snatch (design check, not a bug)
Trigger a Gil Snatch with under 1500 gil: it should take everything. The
floor is gone on purpose.
