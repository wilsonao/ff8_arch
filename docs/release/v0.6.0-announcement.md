# v0.6.0 — Story Keys (draft, not posted)

FF8 finally has doors. This release adds **Story Keys**: twenty "Key: <area>"
items, one per world-map entrance (Balamb, Dollet, Timber, Deling City,
Winhill, Trabia Garden, Esthar City, Lunar Gate, the chocobo forests, ...).
Without the key the town's entrance simply does not work: you walk onto it,
nothing happens, and the client says `Locked: Key: Dollet`. The moment the
key lands, the door works again, right where you stand.

No story faking, no file patching. The game decides every step from a small
entrance table whether a tile leads into a town; the client rewrites one word
of that table per missing key and puts it back when the key arrives.

Two modes (`story_keys`, off by default while the feature is new):

- **areas** — every key is a real door and the checks inside (draw points,
  magazines, rare cards, optional bosses) need it in logic, but the story
  path is never blocked: while the story wants you inside, the door opens on
  its own.
- **story** — the doors the main line walks through stay shut too, so
  advancing the story needs keys other players hold: Fire Cavern, Galbadia
  Garden, the Tomb, Deling City, Missile Base, Trabia Garden, Edea's House,
  the Great Salt Lake, Esthar City, Lunar Gate, Sorceress Memorial, Tears'
  Point. Balamb town and the Fire Cavern keys are yours from the start so the
  opening hour never waits on another world.

Keys carry their `/ff8warp` destination (Fast Travel adds nothing alongside
them). New preset **Story Keys** = Staircase + `story_keys: story`. Sphere
report on the default options: 59 checks in sphere 1 and 10-17 spheres;
with story keys 46 and 13-16.

What keys do not do: open a town before the story does. Early entry works
mechanically, but a town's interior scenes assume the story state (Deling
City's hotel lounge soft-locked in testing), so it stays off until each town
has been surveyed.

Tracker pack 0.12.0 shows the keys and mirrors the new rules. Stability
note as with v0.4.0: v0.5.0 remains the stable release; report anything odd
with `/ff8` output and the client log.
