**FF8 (Steam 2013) beta update — v0.4.0: the seed is a staircase now** 🪜

⚠️ **Stability note first.** v0.4.0 carries the early-Ragnarok work (Vehicle Unlocks / Vehicle Gates), which pokes the game's world map in ways the previous releases never did. It has been through one live session, not a full playthrough, so expect rough edges — a ship parked somewhere odd, a spawn that needs one more battle, a save made aboard behaving strangely. Both vehicle options are **off by default**, and the sphere changes below are generation-only, but if you want the most stable experience for a long multiworld, stay on **v0.3.0** for now and report anything you hit on v0.4.0 here.

You were right about sphere 1. Measured the way a player feels it (free story
beats collapsed), a default seed opened **220 of 455 checks** the moment you
pressed New Game, then dumped the other 190 the instant six GFs showed up.
Two plateaus, five real spheres.

What changed:

- **18 story beats instead of 9 regions.** Disc 2 is now Prison → Missile
  Base → Garden Revolt → FH → Balamb Liberation → Garden War; Disc 3 is Edea's
  House → Esthar → Lunar Base → Sorceress Memorial → Lunatic Pandora.
- **Story Gates** (new option, on by default at `normal`): each beat asks for
  a few more items to count as in logic — a rising ladder of GFs plus your
  character / junction / command unlocks. Same idea as the old Disc 3 GF
  count, extended to every beat; the game never physically stops you, it
  shapes where progression lands and what the tracker shows. `tight` for the
  hardcore version, `off` for the old behaviour.
- **Result on a default seed:** sphere 1 is **59 checks, all in Disc 1**, and
  the seed plays as **8 to 13 steps** (tight: ~25 checks, 11 to 15 steps).
- **Open world half:** with Vehicle Unlocks on, the Ragnarok item is a real
  key — the world-map draw points of Centra, Trabia, Esthar, and the islands
  open with the ship *or* the story, so an early Ragnarok pulls Disc 3 islands
  into your second sphere. The ship now stays with you for the whole game and
  re-appears beside you after every town visit. (The Garden item is gone: a
  mobile Garden replaces the static one, which locked you out of home base.)
- **Vehicle Gates** (experimental, off): the story's own Ragnarok is parked
  out at sea until the item arrives, so free flight is a genuine key gate.
- **Tracker:** the PopTracker pack (0.10.0) mirrors the ladder exactly and
  counts your unlocks and vehicles; UT regenerates as before.
- New **Staircase** preset: tight gates + vehicles + every check group.

Try `story_gates: tight` if `normal` still feels wide, and tell me where the
steps feel wrong — the ladder numbers are tunable per beat.
